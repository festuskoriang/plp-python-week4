# Python Functions Assignment

- `toolbox.py` — Defines and demonstrates functions for doubling a number, checking whether a score passes, and greeting someone.
- `welcome.py` — Defines and demonstrates a function that welcomes a person by name.

The `greet` function in `toolbox.py` was the hardest to write because it accepts an optional greeting as well as a name. That makes it more flexible than the other functions, which each handle a single straightforward operation.
